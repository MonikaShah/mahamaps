IMD Rainfall Dataset

This rainfall dataset contains daily gridded rainfall data from the India Meteorological Department (IMD). The dataset covers the period from 1951 onward and is provided on a 0.25° × 0.25° latitude- longitude grid. Each grid cell contains daily rainfall in mm/day.

The current NetCDF dataset contains 30 × 37 = 1,110 grid cells and 27,394 daily observations. The data are stored in PostgreSQL/PostGIS using an array-based time-series structure, allowing efficient extraction of daily rainfall for grid cells and villages.
