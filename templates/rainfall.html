Rainfall Dataset

The rainfall map displays rainfall observations across Maharashtra districts using daily rainfall data.

The dataset contains rainfall records from 1981 onwards. Users can select different aggregation periods to explore rainfall patterns across Maharashtra.

For Daily Average, users can select a start date and end date. For Weekly, Monthly, Seasonal and Annual rainfall, users can select the year and corresponding period.
