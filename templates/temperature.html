Temperature Dataset

The temperature map displays maximum temperature observations across Maharashtra districts using daily Tmax data.

Users can select different aggregation periods to explore temperature patterns across Maharashtra.

For Daily Average, users can select a start date and end date. For Weekly, Monthly, Seasonal and Annual temperature, users can select the year and corresponding period.

Temperature values are displayed in degrees Celsius (°C).
